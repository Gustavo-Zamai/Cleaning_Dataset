## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- Python
- Pandas


---
## 💻 Projeto

Projeto de limpeza da base de dados, de vários restaurantes, onde contém informações sobre as avaliações, valor por pessoa, etc.

---
## 📑 Aprendizado

Durante esse projeto aprendi: 
- Realizar limpeza de dados duplicados
- Remoção de uma, ou várias colunas
- Tratar valores NaN
- Renomear colunas

---

## 📊 Dataset

O Dataset utilizado pode ser acessado atraves do link: https://www.kaggle.com/datasets/rishikeshkonapure/zomato

---

## 🎯 Objetivos

Limpeza dos dados:
 - Deletar colunas redundantes.
 - Renomear colunas.
 - Excluir duplicações.
 - Limpeza das colunas de forma individual.
 - Remover os valores Nan do Dataset

Visualização dos dados:
- Restaurantes que fazem entregas online ou não
- Restaurantes que permitem ou não reserva de mesa
- Tarifa de reserva de mesa vs. Tarifa
- Melhor localização
- Relação entre localização e classificação
- Tipo de restaurante
- Tipo de Resto Gaussiano e classificação
- Tipos de serviços
- Relação entre tipo e classificação
- Custo do restaurante
- Número de restaurantes em um local
- Tipo de restaurante
- Restaurante mais famoso em Bengaluru

Análise de Regressão:
- Regressão Linear
- Regressão em Árvore de Decisão
- Regressão em Floresta Aleatória
